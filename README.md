
# Insurance Claims Fraud Analysis

## Project Overview
This project focuses on analyzing insurance claims data to identify suspicious patterns, detect potential fraudulent claims, and understand insurance claim trends.

The project uses Python, SQL, Machine Learning concepts, and Microsoft Power BI to perform data analysis and create interactive dashboards.

## Project Objectives
- Analyze insurance claim data.
- Identify suspicious claim patterns.
- Perform data cleaning and preprocessing.
- Analyze claim trends using SQL.
- Explore fraud detection techniques.
- Build interactive Power BI dashboards.
- Generate useful business insights.

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Data cleaning and preprocessing |
| Pandas | Data manipulation |
| SQL | Data analysis and querying |
| Power BI | Dashboard and visualization |
| CSV | Dataset storage |
| Machine Learning | Fraud detection exploration |
